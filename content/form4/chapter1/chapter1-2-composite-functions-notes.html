Composite Functions — Notes

A clear guide to combining functions and evaluating composite functions step by step.

1.2 Composite Functions
ConceptNotationFinding fg(x)Finding gf(x)Finding a ValueUnknown FunctionsQuick Summary
01

What is a Composite Function?

A composite function is formed when the output of one function is used as the input of another function.

Key idea

For f(g(x)), apply g first, then apply f.

x → g → g(x) → f → f(g(x))
02

Composite Function Notation

In this chapter, the notation fg(x) means f(g(x)). It does not mean f(x) × g(x).

fg(x) = f(g(x))
gf(x) = g(f(x))
Exam Tip

The function closest to x is performed first.

03

Finding fg(x)

Suppose f(x) = 2x + 3 and g(x) = x - 4.

Step 1 — Start with f(g(x))

fg(x) = f(g(x))

Step 2 — Substitute g(x) into f

f(g(x)) = 2(x - 4) + 3

Step 3 — Simplify

fg(x) = 2x - 5
04

Finding gf(x)

Using the same functions, now find gf(x) = g(f(x)).

Step 1

gf(x) = g(f(x))

Step 2 — Substitute f(x) into g

g(f(x)) = (2x + 3) - 4

Step 3 — Simplify

gf(x) = 2x - 1
Important

In general, fg(x) ≠ gf(x). The order of the functions matters.

05

Finding a Value of a Composite Function

Given f(x) = x + 2 and g(x) = 3x, find fg(4).

Method

g(4) = 3(4) = 12
f(12) = 12 + 2 = 14

Therefore, fg(4) = 14.

06

Finding an Unknown Function

Sometimes a question gives a composite function and asks you to determine an unknown function.

Example

Given f(x) = 2x + 1 and fg(x) = 4x - 5, find g(x).

f(g(x)) = 2g(x) + 1
2g(x) + 1 = 4x - 5
g(x) = 2x - 3
07

Quick Summary

  • fg(x) = f(g(x)).
  • For f(g(x)), apply g first, then f.
  • For g(f(x)), apply f first, then g.
  • Generally, fg(x) ≠ gf(x).
  • For numerical values, work from the inside out.
