FORM 4 · CHAPTER 1 · 1.2

Composite Functions — Exercise

Practise composite functions from basic substitution to SPM-style problem solving.

12 QUESTIONSSuggested time: 30 minutes
01

Basic composition

Given f(x) = 2x + 3 and g(x) = x - 5, find fg(x).

02

Reverse order

Given f(x) = 3x - 1 and g(x) = 2x + 4, find gf(x).

03

Compare the order

Given f(x) = x + 2 and g(x) = 4x, find fg(x) and gf(x). Are they equal?

04

Evaluate a composite function

Given f(x) = x² + 1 and g(x) = 2x - 3, find fg(4).

05

Two-step evaluation

Given f(x) = 5x - 2 and g(x) = x + 1, find gf(-3).

06

Find an unknown constant

Given f(x) = 2x + k and g(x) = x - 3. If fg(2) = 5, find the value of k.

07

Find an unknown function

Given f(x) = 3x + 2 and fg(x) = 6x - 4, find g(x).

08

Composite equation

Given f(x) = 2x - 1 and g(x) = x + 4, solve fg(x) = 13.

09

Algebraic composition

Given f(x) = x² - 2 and g(x) = x + 3, find and simplify fg(x).

10

Working backwards

Given f(x) = 4x - 1 and fg(x) = 8x + 7, determine g(x).

11

SPM-style problem

Functions f and g are defined by f(x) = 2x - 5 and g(x) = x² + 1. Find fg(2) and gf(2). Hence explain why the order of composition matters.

12

Challenge

Given f(x) = ax + 1 and g(x) = 2x - 3. If fg(4) = 11, find a. Hence determine gf(x).
