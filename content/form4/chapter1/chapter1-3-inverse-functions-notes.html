Inverse Functions — Notes

A clear guide to the key ideas and skills in 1.3 Inverse Functions.

1.3 Inverse Functions
ConceptInverse NotationOne-to-one FunctionFinding f⁻¹(x)Checking the InverseFinding a ValueQuick Summary
01

What is an Inverse Function?

An inverse function reverses the effect of a function. If a function maps an input to an output, its inverse maps that output back to the original input.

Key idea

A function and its inverse work in opposite directions.

x → f → f(x) → f⁻¹ → x

For example, if f maps 2 to 7, then the inverse function maps 7 back to 2.

02

Inverse Function Notation

The inverse function of f is written as f⁻¹. Therefore, its function notation is f⁻¹(x).

f⁻¹(x) = inverse function of f(x)
Important

f⁻¹(x) does not mean 1/f(x). The notation f⁻¹ represents the inverse function.

03

One-to-one Function

A function must be one-to-one on the specified domain in order to have an inverse function.

Remember

Different input values must produce different output values.

Different inputs → Different outputs

If two different inputs give the same output, the function is not one-to-one on that domain and an inverse function cannot be defined on that domain.

04

Finding f⁻¹(x)

Use the following steps to find the inverse of a function.

Step 1 — Write y = f(x)

Given f(x) = 3x + 5:

y = 3x + 5

Step 2 — Interchange x and y

x = 3y + 5

Step 3 — Make y the subject

x − 5 = 3y
y = (x − 5)/3

Step 4 — Write the inverse

f⁻¹(x) = (x − 5)/3
Exam Tip

The safest method is: replace f(x) with y → interchange x and y → solve for y → write f⁻¹(x).

05

Checking the Inverse Function

We can verify that two functions are inverses by using composite functions.

f(f⁻¹(x)) = x
f⁻¹(f(x)) = x

Example

For f(x) = 3x + 5 and f⁻¹(x) = (x − 5)/3:

f(f⁻¹(x)) = 3((x − 5)/3) + 5 = x

Therefore, the inverse is verified.

06

Finding a Value of an Inverse Function

If f(a) = b, then the inverse reverses the mapping:

f⁻¹(b) = a

Example

Given f(4) = 13, find f⁻¹(13).

Since f maps 4 to 13, the inverse maps 13 back to 4.

f⁻¹(13) = 4
07

Quick Summary

  • An inverse function reverses the original function.
  • The inverse is written as f⁻¹(x).
  • The function must be one-to-one on the specified domain.
  • To find the inverse: write y → interchange x and y → solve for y.
  • Check using f(f⁻¹(x)) = x and/or f⁻¹(f(x)) = x.
  • If f(a) = b, then f⁻¹(b) = a.
