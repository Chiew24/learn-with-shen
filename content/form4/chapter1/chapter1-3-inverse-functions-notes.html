Inverse Functions — Notes

A step-by-step guide to understanding and finding inverse functions.

1. What is an Inverse Function?

An inverse function reverses the effect of a function. If a function maps an input x to an output y, its inverse maps y back to x.

f⁻¹(f(x)) = x    and    f(f⁻¹(x)) = x

2. Inverse Function Notation

The inverse of f(x) is written as f⁻¹(x).

Important: f⁻¹(x) does not mean 1/f(x). It means the inverse function of f.

3. How to Find f⁻¹(x)

  1. Write y = f(x).
  2. Interchange x and y.
  3. Solve the new equation for y.
  4. Replace y with f⁻¹(x).

Example

Given f(x) = 3x + 5, find f⁻¹(x).

Step 1: y = 3x + 5

Step 2: x = 3y + 5

Step 3: x − 5 = 3y

y = (x − 5)/3

Therefore, f⁻¹(x) = (x − 5)/3.

4. Checking an Inverse Function

We can check whether two functions are inverses by composing them.

f(f⁻¹(x)) = x    and    f⁻¹(f(x)) = x

If both results equal x, the functions are inverses of each other.

5. Finding a Value of an Inverse Function

If f(a) = b, then f⁻¹(b) = a.

Example

Given f(4) = 9, find f⁻¹(9).

Since f(4) = 9, the inverse reverses this mapping.

Therefore, f⁻¹(9) = 4.

6. Important Condition

For a function to have an inverse function, it must be one-to-one on the specified domain. A one-to-one function gives a unique input for each output.

7. Common Mistakes

  • Do not confuse f⁻¹(x) with 1/f(x).
  • Remember to interchange x and y before solving for y.
  • Check the inverse by composition when needed.
  • Pay attention to the given domain and range.

Quick Summary

f(x) → apply f⁻¹ → x

f⁻¹(x) → reverses f(x)

f(f⁻¹(x)) = x
f⁻¹(f(x)) = x
