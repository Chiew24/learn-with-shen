FORM 4 · CHAPTER 1 · 1.3

Inverse Functions — Exercise

Practise inverse functions from basic questions to SPM-style problem solving.

12 QUESTIONSSuggested time: 30 minutes
01

Basic inverse

Given f(x) = 2x + 3, find f⁻¹(x).

02

Linear function

Given g(x) = 5x - 7, find g⁻¹(x).

03

Evaluate an inverse

Given f(x) = 3x + 1, find f⁻¹(10).

04

Work backwards

Given f(6) = 15, find f⁻¹(15).

05

Check the inverse

Given f(x) = 4x - 5 and g(x) = (x + 5)/4, show that f and g are inverse functions.

06

Find an unknown constant

Given f(x) = ax + 4 and f(3) = 13, find a and hence find f⁻¹(x).

07

Inverse notation

Given f⁻¹(x) = 2x - 1, find f(x).

08

Domain and range

For f(x) = 2x + 1, where x ∈ {0, 1, 2, 3}, state the domain and range of f. Hence state the domain and range of f⁻¹.

09

Algebraic inverse

Given f(x) = (x - 2)/3, find f⁻¹(x) and verify your answer using one composition.

10

One-to-one

Consider f(x) = x² for x ∈ {-2, -1, 0, 1, 2}. Explain whether f has an inverse function on this domain.

11

SPM-style problem

Given f(x) = 3x - 2 and g(x) = (x + 2)/3, find f⁻¹(x) and determine whether g(x) = f⁻¹(x).

12

Challenge

Given f(x) = (2x + 5)/(x - 1), find f⁻¹(x), stating any restriction required for the inverse function.
