Functions — Notes

A clear guide to the key ideas and skills in 1.1 Functions.

1.1 Functions
ConceptFunction NotationDomain & RangeTypes of FunctionsQuick Summary
01

What is a Function?

A function is a relation in which each element of the domain is associated with exactly one element of the codomain.

Key idea

Every input must have one and only one output.

Input → Function → Output

For example, if f(x) = 2x + 1, every value of x gives exactly one value of f(x).

02

Function Notation

A function can be written as f : x → f(x). The notation f(x) means the output of function f when the input is x.

f(x) = 3x - 2

To find f(4), substitute x = 4:

Example
f(4) = 3(4) - 2 = 10
Exam Tip

When finding f(a), replace every x in the function with a.

03

Domain, Codomain and Range

The domain is the set of possible input values. The codomain is the set of possible output values stated for the function. The range is the set of actual output values produced.

Remember

Domain → input
Range → actual output

When reading a mapping diagram, check where every domain element goes. A valid function cannot have one input pointing to two different outputs.

04

Types of Functions

One-to-one function

Different elements in the domain map to different elements in the range.

Many-to-one function

Two or more different domain elements may map to the same range element.

Important

A relation is not a function if one input is associated with more than one output.

05

Quick Summary

  • Function: each input has exactly one output.
  • f(x): output of f for input x.
  • Domain: set of input values.
  • Range: set of actual output values.
  • One-to-one: different inputs have different outputs.
  • Many-to-one: different inputs can share the same output.
