FORM 4 · CHAPTER 1 · 1.1

Functions — Exercise

Practise the skills from 1.1 Functions. Try each question before checking your working.

10 QUESTIONSSuggested time: 25 minutes
01

Function notation

Given f(x) = 4x - 7, find f(5).

02

Evaluate a function

Given g(x) = x² + 3x - 2, find g(-2).

03

Find an unknown

Given h(x) = 5x + 1 and h(a) = 21, find the value of a.

04

Function or not?

A relation maps 1 → 3, 2 → 5, 3 → 5 and 4 → 8. Is this relation a function? Give a reason.

05

Domain

State the domain of the function f : x → 2x + 1 for x ∈ {1, 2, 3, 4}.

06

Range

For f(x) = 2x - 1, where x ∈ {0, 1, 2, 3}, state the range.

07

One-to-one or many-to-one

Consider f(x) = x² for x ∈ {-2, -1, 0, 1, 2}. State whether the function is one-to-one or many-to-one.

08

Mapping

The domain is {1, 2, 3} and the range is {4, 5}. If f(1) = 4, f(2) = 5 and f(3) = 5, state the type of function.

09

Problem solving

A function is defined by p(x) = 3x + k. Given that p(2) = 11, find k and hence find p(6).

10

Challenge

Given q(x) = x² - 4x + 3, find q(1), q(2) and q(5). Hence state the range for the given three input values.
