FORM 4 · CHAPTER 1

Functions

Understand the fundamental concepts of functions, composite functions and inverse functions.

Chapter 1
1.1 Functions1.2 Composite Functions1.3 Inverse Functions
1.1

Functions

A function is a relationship where each input has exactly one output.

Key Idea

If a function is written as

f(x) = 2x + 3

the value of the function depends on the input value of x.

Example 1

Given

f(x) = 3x + 2

Find f(4).

Solution

Substitute x = 4:

f(4) = 3(4) + 2
f(4) = 14
Exam Tip

When you see f(a), replace every x in the function with a.

1.2

Composite Functions

A composite function is formed when one function is applied after another function.

Key Idea

If we have functions f and g, the composite function is written as:

(fg)(x) = f(g(x))

This means we apply g first, followed by f.

Example 2

Given

f(x) = 2x + 1
g(x) = x²

Find f(g(x)).

Solution

Since f(x) = 2x + 1:

f(g(x)) = 2g(x) + 1 = 2x² + 1
Remember

For f(g(x)), calculate the inside function g(x) first.

1.3

Inverse Functions

An inverse function reverses the operation of the original function.

Key Idea

The inverse of f(x) is written as:

f⁻¹(x)

A function and its inverse undo each other's operations.

Example 3

Given f(x) = 2x + 5, find f⁻¹(x).

Solution

Write y = 2x + 5, interchange x and y, then make y the subject:

x = 2y + 5
y = (x - 5) / 2

Therefore:

f⁻¹(x) = (x - 5) / 2
Exam Tip

Interchange x and y, then make y the subject.
